# 우리 동네 생태 퀴즈

## 프로젝트 개요
Python 표준 라이브러리로 만드는 콘솔 퀴즈 게임입니다.

## 주제 선정 이유
시민생물조사단 활동에서 만난 생물과 환경 지식을 퀴즈로 복습하기 위해 선택했습니다.

## 실행 방법
Python 3.10 이상이 필요합니다. 외부 라이브러리 설치는 필요하지 않습니다.

```bash
git clone https://github.com/minjung-workshop/eco-quiz-m2.git
cd eco-quiz-m2
python3 main.py
```

## 기능 목록
1. 퀴즈 풀기: 등록된 문제를 풀고 정답 여부와 최종 점수를 확인합니다.
2. 퀴즈 추가: 문제, 선택지 4개, 정답 번호를 입력하고 파일에 저장합니다.
3. 퀴즈 목록: 등록된 문제를 번호와 함께 확인합니다.
4. 점수 확인: 완료한 게임의 최고 점수를 확인합니다.
5. 종료: 퀴즈와 점수를 저장하고 종료합니다.

점수는 정답 수를 전체 문제 수로 나눈 뒤 100을 곱하고 반올림합니다.
아직 게임을 완료하지 않았다면 기록이 없다는 안내를 표시합니다.
진행 중인 게임을 중단하면 해당 게임의 점수는 기록하지 않습니다.

## 파일 구조
| 파일 또는 폴더 | 역할 |
|---|---|
| main.py | 게임 객체를 만들고 실행하는 시작 파일 |
| quiz.py | 개별 문제를 표현하는 Quiz 클래스 |
| game.py | 메뉴, 출제, 등록, 목록, 점수, 저장을 관리하는 QuizGame 클래스 |
| data.py | 기본 생태 퀴즈 5개 생성 |
| input_utils.py | 숫자 범위 검사와 빈 문자열 입력 검사 |
| state.json | 퀴즈와 최고 점수를 보관하는 데이터 파일 |
| logs/ | 명령 실행과 기능 검사 기록 |
| evidence/ | 제출용 실행 화면 캡처 보관 위치 |
| .gitignore | 임시 파일과 Python 캐시 등을 Git에서 제외 |

## 데이터 파일 설명
데이터는 프로젝트 루트의 state.json에 UTF-8 인코딩으로 저장합니다.
실행한 터미널의 현재 위치와 관계없이 game.py가 있는 폴더를 기준으로 찾습니다.

```json
{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": ["선택지 1", "선택지 2", "선택지 3", "선택지 4"],
      "answer": 1
    }
  ],
  "best_score": null
}
```

- quizzes: 문제 목록입니다. 각 문제에는 question, choices, answer가 있습니다.
- choices: 비어 있지 않은 문자열 4개입니다.
- answer: 화면에 표시되는 정답 번호인 1~4의 정수입니다.
- best_score: 0~100의 최고 점수입니다. 게임 완료 기록이 없으면 null입니다.
- 퀴즈 추가, 최고 점수 갱신, 프로그램 종료 시 저장합니다.
- 임시 파일 state.json.tmp에 먼저 작성한 뒤 state.json을 교체합니다.
- 파일이 없으면 기본 퀴즈로 시작합니다.
- JSON 문법이나 데이터 형식이 잘못되면 안내하고 기본 퀴즈로 시작합니다.
- 손상 파일은 state.corrupt-시간값.json으로 보관합니다.
- 읽기 오류나 손상 파일 보관 실패 시 기존 파일 보호를 위해 저장하지 않습니다.
- 쓰기 오류가 발생하면 저장 실패 안내를 표시합니다.

## 입력 및 예외 처리
숫자 입력은 앞뒤 공백을 제거하고 빈 입력, 숫자가 아닌 입력,
허용 범위를 벗어난 입력을 검사하여 다시 입력받습니다.
문제와 선택지도 빈 내용으로 등록할 수 없습니다.
Ctrl+C 또는 EOF가 발생하면 안내하고 가능한 경우 저장 후 종료합니다.
